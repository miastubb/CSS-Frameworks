# The Wire™

A social media front-end prototype built with **Vite** and **Tailwind CSS** for the Noroff CSS Frameworks course assignment.

## Project Description

The Wire™ is a responsive social media interface that demonstrates the use of Tailwind CSS to create a modern, mobile-friendly user experience.

The project includes:

- Landing page
- Login page
- Register page
- Feed page
- Profile page
- Create Post page

This project focuses on front-end design, responsive layouts, reusable components, and HTML form validation.

## Built With

- Vite
- Tailwind CSS
- JavaScript
- HTML5

## Installation

Clone the repository:

```bash
git clone <repository-url>
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
