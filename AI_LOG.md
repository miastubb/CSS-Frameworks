# AI_LOG.md

## AI Usage Log

AI assistance was used throughout the development of this project as a learning aid, debugging assistant, and source of technical explanations.

### Areas Where AI Was Used

#### Project Setup

- Assistance with setting up Vite and Tailwind CSS.
- Guidance on configuring project structure and multi-page routing.
- Help understanding how GitHub Pages deployment works with Vite.

#### Tailwind CSS

- Explanations of Tailwind utility classes and responsive design techniques.
- Suggestions for converting previous CSS-based layouts into Tailwind components.
- Help creating reusable button and card styles.

#### Responsive Design

- Guidance on card layouts, image sizing, spacing, and mobile-friendly navigation.

#### Debugging

- Help identifying incorrect paths and image references.
- Assistance troubleshooting GitHub Pages deployment issues.

#### UI and UX Improvements

- Suggestions for improving page layouts and visual hierarchy.
- Assistance creating realistic demo content for feed posts.
- Recommendations for improving spacing, typography, and consistency between pages.

### How AI Was Used

AI was used as a learning and support tool. All implementation decisions, code integration, testing, and final project submissions were completed by myself. AI-generated suggestions were reviewed, modified when necessary, and adapted to fit the project requirements.

### Reflection

Using AI helped speed up troubleshooting and provided explanations for unfamiliar concepts. The tool was primarily used to better understand Tailwind CSS, responsive design techniques, project structure, and deployment workflows while maintaining responsibility for the final implementation.
